# AuraDesk (极光桌面)

> **极简、高效、深度的现代化 Windows 桌面增强套件**  
> 专为 Windows 11 深度打造，融合 Rainmeter 风格常驻信息挂件、极速零延迟瞬开启动台、桌面快捷方式安全脱钩与现代化毛玻璃程序坞。

---

## 🌟 核心特性

### 1. 桌面底层常驻信息栏（雨滴挂件模式）
- **绝不抢焦，常驻底层**：窗口停靠在操作系统桌面底层（`HWND_BOTTOM`），鼠标靠近不乱弹、移开不收缩，静止优雅常驻。
- **活动窗口避让（遮挡自隐）**：智能探测前台应用。当浏览器、IDE 或游戏全屏/最大化覆盖该区域时，信息栏自动隐退，彻底解决遮挡网页关闭与最小化按钮的烦恼；返回桌面即刻清晰呈现。
- **系统状态聚合**：优雅集成数字时钟、硬件传感器采样（CPU/内存负载、网络实时吞吐）、音乐胶囊与快捷控制中心。

### 2. 彻底关闭多余动画（极速瞬开响应）
- **零过渡延迟**：彻底移除了拖沓的 300ms 补间容器缩放动效，点击图标瞬间弹出面板、按 Esc 或点击外部瞬间隐退，带来原生 Windows 控件般干脆利落的响应。
- **Dock 栏即时跟手**：移除了持续计算的物理缓动放大网格插值与边缘滑动粘滞感，操作精准丝滑。
- **免代码自由切换**：设置中心提供「彻底关闭过渡动效（极速秒开模式）」开关，随心按需微调。

### 3. 桌面快捷方式彻底脱钩（删除桌面图标不失效）
- **安全克隆备份**：从桌面或文件夹拖入快捷方式时，内部自动将 `.lnk` 复制一份到安全隔离数据目录（`Data/Shortcuts/`），桌面的临时图标拖完即可放心随手删除。
- **Modern / UWP 虚拟协议容错直开**：对 ChatGPT、微软商店应用等现代打包软件原生支持 AUMID 协议调用。即使桌面图标已被删除，也能通过系统虚拟通道 `shell:AppsFolder\{AUMID}` 瞬间拉起应用，告别“目标已不在原处”的警告感叹号。

### 4. 极致清爽与隐私自主
- **零商业侵扰**：全代码彻底剔除所有“赞助支持”、“收款码”、“资助”弹窗与代码残留。
- **干净看板**：移除了繁琐的启动台顶部分区 Tab 与新建页标记，回归纯净全屏磁贴看板。
- **防打扰锁定**：Dock 栏增加“窗口遮挡或全屏时阻止自动弹出”，沉浸办公与游戏时不再被屏幕底部的误触打扰。
- **进程与配置完全隔离**：独立命名空间与互斥体守护，不与任何第三方桌面软件产生冲突。

## 🛠️ 系统要求与技术栈

- **操作系统**：Windows 11 x64（Build 22000 及以上）
- **运行时环境**：.NET 10 SDK（Windows Desktop 工作负载，目标框架 `net10.0-windows10.0.26100.0`）
- **核心架构**：C# 13 / WPF / Windows COM 外壳互操作 / DirectComposition 材质渲染

## 🚀 编译构建与运行

### 1. 源码编译 (Release)
```powershell
dotnet build src/GlassDesk.App/GlassDesk.App.csproj -c Release
```
编译产物输出于：`src/GlassDesk.App/bin/Release/net10.0-windows10.0.26100.0/`

### 2. 独立发布单文件 / 便携包
```powershell
dotnet publish src/GlassDesk.App/GlassDesk.App.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

### 3. 运行体验
```powershell
dotnet run --project src/GlassDesk.App/GlassDesk.App.csproj -c Release
```
所有配置文件、图标缓存与快捷方式统一存储于程序同级目录的 `Data/` 文件夹中，支持真正的绿色免安装便携使用。
